# 🚗 CleanDrive

### CO₂ Emission Predictor

CleanDrive is a machine learning web application that predicts vehicle CO₂ emissions based on user inputs such as engine size, fuel type, transmission, and vehicle class. The application classifies emissions and encourages environmentally conscious driving.

---

## Features

- Vehicle emission prediction
- Machine learning model
- Streamlit interface
- Interactive user input
- Emission classification

---

## Tech Stack

- Python
- Streamlit
- Scikit-learn
- Pandas
